# PuriSound — 데이터 분석 & 서비스 기획

기준 문서: 팀 **`puri_sound_overview.html`** 의 BX/CX·데이터 전략 섹션과 동일 수치·정의를 사용합니다.

---

## 1. 서비스 정의 (overview)

주변 소음을 실시간 감지·분석하여 유형·주파수에 맞는 대응 사운드(Brown, Pink, White, 자연음)를 분사하고 LED 피드백을 제공해 수면·집중·휴식을 보호하는 **생활 밀착형 스마트홈 서비스**.

### YAMNet의 역할 (구현 연계)

- Pi가 약 4초 WAV를 외부 YAMNet 서버로 전송 → 521종 라벨·score 수신  
- 단순 dB이 아니라 **소리 맥락**을 보조 분류 (FFT 결정과 함께 사용)  
- 서버 OFF 시에도 FFT 전용으로 동작 가능  

상세 서버: 루트 [`PuriSound_YAMNET/README.md`](../PuriSound_YAMNET/README.md)

## 4. 분석 파이프라인 (최종 채택 = overview)

1. **수집** — 유튜브, 블라인드, 네이버 카페, 지식인, 당근마켓  
2. **전처리** — 특수문자·이모지·짧은 글, 동의어, 불용어  
3. **임베딩** — KoSentenceBERT **768d**  
4. **차원 축소** — **PCA 150d → UMAP 5d** (최종)  
5. **클러스터** — K-Means **K=3** (Elbow·Silhouette)  
6. **IPA** — Importance × Satisfaction → 기회 영역 (충격음, 갈등·보복 우려, 생활·펫 소음 등)

## 6. 서비스 기획 (5+1 모드)

* Pain / CX: overview CX 섹션과 동일 — 통제감 회복, 맞춤 사운드, 비대면 갈등 완화  
* 모드: 층간소음 마스킹 · 외부 소음 차폐 · 집중 몰입 · 딥슬립 케어 · 펫 홈 케어 + **AI 통합**

### 액터 → 모드

| 액터 | 우선 모드 |
|------|-----------|
| 0 | 층간소음 마스킹, 딥슬립, AI 자동 |
| 1 | AI 자동, 취약 시간 딥슬립·집중 (분쟁 예방) |
| 2 | 외부 차폐, 펫 홈 케어, 집중 몰입 |

### UX 모드 ↔ 디바이스

앱의 모드 이름 ≠ 파이썬 enum. 구현은 `noiseType`(`brown`/`pink`/`white`)·`noiseVersion`·`autoMasking` + 9번 분류 결과.

| 모드 | 디바이스 힌트 |
|------|----------------|
| 층간소음 마스킹 | brown 저음역 |
| 외부 소음 차폐 | pink·자연음 |
| 집중 몰입 | pink/white |
| 딥슬립 | brown 소프트 + 페이드 |
| 펫 홈 케어 | 진정 음원 |
| AI 통합 | 9 → 18 자동 |

시나리오 예: 새벽 발망치(ACTOR0) / 게시판 확전 전 AI 자동(ACTOR1 관점) / 강아지 짖음(ACTOR2) — 루트 README와 동일.
