4_loadtest
================================================================================

작성일: 2026-06-17
경로: /data/4_loadtest


개요
--------------------------------------------------------------------------------

LED + 스피커 + 마이크를 동시에 30분간 돌리는 통합 부하 테스트입니다.
3개 스레드가 병렬로 동작하며, 진행 상황과 오류를 load_test.log에 기록합니다.

2026-06-17 기준 30분 테스트 완료, 오류 0건 확인됨.


주요 파일
--------------------------------------------------------------------------------

  load_config.py   테스트 시간, LED/스피커/마이크 설정, 로그 경로
  load_test.py     메인 (LED·스피커·마이크 3스레드 + 상태 출력)
  run.sh           1_LED venv Python으로 실행하는 래퍼
  load_test.log    실행 로그 (자동 생성/덮어쓰기)


실행 방법
--------------------------------------------------------------------------------

  cd /data/4_loadtest
  python3 load_test.py              # 30분 (ensure_venv 자동 전환)
  python3 load_test.py -t 5         # 5분
  ./run.sh                          # venv 직접 지정

  # 또는
  /data/1_LED/venv/bin/python3 load_test.py


동작 구조
--------------------------------------------------------------------------------

  LED 스레드     : rpi_ws281x, 색 전환 + 무지개 + 체이스 애니메이션
  스피커 스레드  : 5초마다 비프, 60초마다 음계 테스트 (speaker_test.py 재사용)
  마이크 스레드  : arecord 연속 녹음, 10초마다 peak/rms 로그
  메인 루프      : 60초마다 전체 통계 출력


의존 모듈
--------------------------------------------------------------------------------

  /data/1_LED   : ensure_venv, rpi_ws281x, LED 설정
  /data/2_speaker/speaker_test.py : 톤 생성·재생 함수 import
  ALSA          : aplay, arecord
  SPI           : /dev/spidev0.0


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 1~3단계(LED, 스피커, 마이크) 통합 안정성 검증
  - 장시간 동시 구동 시 GPIO/ALSA/USB 충돌 여부 확인
  - 실제 PuriSound 통합 앱의 프로토타입 구조 (멀티스레드)


주요 이슈
--------------------------------------------------------------------------------

[1] LED는 1_LED venv 필수
  ensure_venv.py로 시스템 python3도 자동 전환됨.
  run.sh는 venv를 명시적으로 사용.

[2] ALSA 장치 번호 하드코딩
  load_config.py: SPEAKER plughw:1,0, MIC plughw:3,0
  실행 시 find_headphones_device/find_usb_mic_device로 자동 탐지 시도.

[3] 스피커 소음이 마이크에 피드백
  부하 테스트 중 peak_max 32075 등 높은 값.
  실제 배포 시 스피커·마이크 배치, AEC(에코 제거) 고려 필요.

[4] 30분 테스트 중 스피커가 계속 소리 냄
  주변 환경·사용자에게 소음 발생. 테스트 시간·볼륨 조절 옵션 추가 검토.

[5] pygame/MP3 미사용
  스피커는 aplay+WAV만 사용. 7_player와 별개 경로.

[6] 2026-06-17 테스트 결과
  LED cycle=370, speaker beep=348 err=0, mic check=3601 err=0
  → 하드웨어·소프트웨어 동시 구동 안정성 확인됨.
