5_noise_client
================================================================================

작성일: 2026-06-17
경로: /data/5_noise_client


개요
--------------------------------------------------------------------------------

외부 YAMNet Flask API 서버에 WAV 파일을 보내 소리 분류 결과를 받는 테스트 클라이언트입니다.
2초짜리 WAV를 만들어 POST /classify 요청을 보냅니다.

9_send_firebase에서 YAMNet 분류 로직의 원형으로 사용됩니다.


주요 파일
--------------------------------------------------------------------------------

  client.py              YAMNet API 테스트 클라이언트
  test_sample.wav        원본 테스트 오디오
  test_2sec.wav          2초로 잘린 테스트 파일 (자동 생성)
  cat_meow_test_2sec.wav 추가 테스트 샘플
  .venv/                 scipy, requests 등 (선택적)


실행 방법
--------------------------------------------------------------------------------

  cd /data/5_noise_client
  python3 client.py
  # 또는 .venv 사용
  .venv/bin/python3 client.py


API 설정
--------------------------------------------------------------------------------

  BASE_URL : http://192.168.0.59:5000
  엔드포인트: POST /classify
  입력     : multipart/form-data, file=audio/wav
  타임아웃 : 30초


프로젝트 내 역할
--------------------------------------------------------------------------------

  - YAMNet 서버 연결·응답 형식 검증용
  - 9_send_firebase가 동일 API를 4초 오디오로 호출
  - 서버가 꺼져 있으면 FFT 분류만으로 폴백 (9_send_firebase)


주요 이슈
--------------------------------------------------------------------------------

[1] YAMNet 서버 IP 하드코딩
  BASE_URL = http://192.168.0.59:5000
  네트워크·서버 환경 변경 시 수정 필요.
  9_send_firebase도 동일 IP 사용 (--yamnet-url로 변경 가능).

[2] 서버 미실행 시 ConnectionError
  YAMNet 서버가 별도 머신에서 Flask로 실행되어야 함.
  Pi 단독으로는 분류 불가.

[3] test_sample.wav 의존
  파일 없으면 "Run the server test setup first" 후 종료.

[4] scipy 의존
  wavfile.read/write에 scipy 필요.
  시스템에 없으면 .venv 사용.

[5] 2초 vs 4초 샘플 길이 차이
  client.py   : 2초
  send_firebase: 4초
  YAMNet 모델 입력 길이에 맞는지 서버 측 확인 필요.
