3_mic
================================================================================

작성일: 2026-06-17
경로: /data/3_mic


개요
--------------------------------------------------------------------------------

USB 마이크(AB13X USB Audio 등) 녹음 테스트 코드입니다.
arecord로 실시간 녹음하며 peak/RMS 레벨 미터를 표시하고, 입력 품질을 자동 판정합니다.

권장 구성: USB 마이크(입력) + 3.5mm 스피커(출력)로 Pi USB 전류 부담을 줄입니다.


주요 파일
--------------------------------------------------------------------------------

  config.py     ALSA 녹음/재생 장치, 샘플레이트, 녹음 시간 설정
  mic_test.py   메인 테스트 (녹음, 레벨 미터, 분석, 선택적 재생/저장)


실행 방법
--------------------------------------------------------------------------------

  cd /data/3_mic
  python3 mic_test.py
  python3 mic_test.py --list              # 녹음 장치 목록
  python3 mic_test.py --playback          # 녹음 내용을 3.5mm로 재생
  python3 mic_test.py -o recording.wav    # WAV 저장
  python3 mic_test.py -t 5                # 5초 녹음


설정값 (config.py)
--------------------------------------------------------------------------------

  ALSA_DEVICE      : plughw:3,0 (USB 마이크, card 3)
  PLAYBACK_DEVICE  : plughw:1,0 (3.5mm 스피커)
  SAMPLE_RATE      : 44100 Hz
  RECORD_SECONDS   : 3초
  의존성           : 시스템 python3 + alsa-utils (arecord, aplay)


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 마이크 단독 동작 확인용 3단계 모듈
  - 4_loadtest가 arecord 기반으로 마이크 스레드 구동 (이 모듈과 유사한 방식)
  - 8_MIC_FFT, 9_send_firebase는 PyAudio 기반으로 더 고급 분석 수행


주요 이슈
--------------------------------------------------------------------------------

[1] plughw:3,0 고정값
  USB 마이크 card 번호는 환경마다 다름.
  find_usb_mic_device()로 자동 탐지하지만 config 기본값은 card 3.

[2] 입력 거의 없음 (peak < 200)
  마이크 연결, 음량, 물리적 위치 확인 필요.

[3] ALSA vs PyAudio 이중 구조
  3_mic     : arecord/aplay (단순 테스트)
  8_MIC_FFT : PyAudio (FFT 실시간 분석)
  9_send_firebase : PyAudio (Firebase 전송)
  통합 시 PyAudio 쪽으로 수렴하는 추세.

[4] 부하 테스트 시 스피커 소리가 마이크에 유입
  4_loadtest 로그에서 peak_max=32075 등 높은 값 관측.
  스피커·마이크 물리적 분리 또는 음향 환경 고려 필요.

[5] venv 불필요
  시스템 python3 + arecord/aplay만 필요.
