13_noise_db
================================================================================

작성일: 2026-06-23
경로: /data/13_noise_db


개요
--------------------------------------------------------------------------------

9_send_firebase가 Firestore에 저장한 noiseEvents를 실시간으로 조회·표시하는
뷰어입니다. YAMNet 라벨, FFT 분류, dB, 주파수, maskingRequired 등을
터미널에 포맷팅하여 출력합니다.

14_noise_ai가 같은 Firebase 데이터를 읽어 마스킹을 결정하기 전,
데이터가 정상 전송되는지 확인하는 모니터링 도구입니다.


주요 파일
--------------------------------------------------------------------------------

  noise_viewer.py   Firebase noiseEvents 조회·표시 메인
  ensure_venv.py    9_send_firebase/.venv 자동 전환
  requirements.txt  firebase-admin
  run.sh            실행 래퍼


실행 방법
--------------------------------------------------------------------------------

  cd /data/13_noise_db
  python3 noise_viewer.py                    # Firestore 실시간 감시 (기본)
  python3 noise_viewer.py --poll             # 주기적 폴링 모드
  python3 noise_viewer.py --interval 2       # 조회 주기 2초
  python3 noise_viewer.py --rtdb             # Realtime DB 사용
  ./run.sh


표시 정보
--------------------------------------------------------------------------------

  detectedAt, noiseEventId, deviceId
  db, frequencyHz, noiseType (brown/pink/white)
  yamnetLabel, confidence, maskingRequired
  fft: label, detail, rmsDbfs, centroidHz, regions(저/중/고음역)
  yamnet: status, primaryLabel, primaryScore

  저장소     : Firestore (기본), --rtdb로 Realtime DB

프로젝트 내 역할
--------------------------------------------------------------------------------

  - 9_send_firebase 전송 데이터 검증·모니터링
  - 14_noise_ai의 입력 소스와 동일 (devices/{deviceId}/noiseEvents)
  - 개발 중 Firebase 파이프라인 디버그용


주요 이슈
--------------------------------------------------------------------------------

[1] firebase.json 의존
  9_send_firebase/firebase.json 없으면 실행 불가.
  서비스 계정 키 Git 업로드·공유 금지.

[2] 9_send_firebase venv 공유
  ensure_venv.py가 9_send_firebase/.venv로 자동 전환.
  firebase-admin 패키지는 9번 venv에 설치.

[3] 실시간 vs 폴링
  기본: Firestore on_snapshot 실시간 감시
  --poll: interval 주기 폴링 (네트워크 부하 적음)

[4] 14번과 데이터 중복 조회
  13번(모니터링)과 14번(마스킹 결정)이 같은 noiseEvents를 읽음.
  14번만 실행해도 결정 로그가 출력되므로 13번은 디버그 전용.
