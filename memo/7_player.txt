7_player
================================================================================

작성일: 2026-06-23 (최초 2026-06-17)
경로: /data/7_player


개요
--------------------------------------------------------------------------------

폴더 내 MP3 파일을 3.5mm 잭(bcm2835 Headphones)으로 최대 3개까지 동시 재생하는 플레이어입니다.
pygame.mixer를 사용하며, 마스킹 사운드(브라운/핑크/화이트 노이즈) 재생용입니다.

2_speaker(aplay+WAV)와 달리 실제 MP3 마스킹 오디오를 루프 재생합니다.


주요 파일
--------------------------------------------------------------------------------

  play_mp3.py   MP3 동시 재생 메인
  마스킹_*.mp3  마스킹 사운드 3개
    - 마스킹_브라운_저음35_06.mp3
    - 마스킹_핑크_중음38_01.mp3
    - 마스킹_화이트_하중음31_01.mp3


실행 방법
--------------------------------------------------------------------------------

  cd /data/7_player
  python3 play_mp3.py
  python3 play_mp3.py /path/to/mp3/folder

  종료: Ctrl+C
  강제 종료: pkill -x play_mp3.py


동작 특징
--------------------------------------------------------------------------------

  - SDL_AUDIODRIVER=alsa, AUDIODEV=plughw:CARD=Headphones,DEV=0
  - 최대 3채널 동시 재생 (MAX_TRACKS=3)
  - 각 MP3 무한 루프 (loops=-1)
  - /tmp/play_mp3.lock 파일 락으로 중복 실행 방지
  - /tmp/play_mp3_state.json 에 재생 상태 기록 (11_led_connect 연동용)
  - 파일명에서 brown/pink/white 노이즈 타입 자동 추출
  - PID 출력 — 종료 시 해당 프로세스를 죽여야 소리 멈춤


의존성
--------------------------------------------------------------------------------

  pygame
  시스템 ALSA (3.5mm 잭)


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 6_FFT에서 분석된 마스킹 사운드의 수동 재생 단계
  - legacy/6_FFT/noise_controller_pi3.py의 마스킹 재생 기능 단순화 버전
  - 11_led_connect가 play_mp3_state.json을 읽어 LED 색상 동기화
  - 14~15번 분리 아키텍처(15_player_ai)가 등장하면서 자동 마스킹은 15번이 담당


주요 이슈
--------------------------------------------------------------------------------

[1] 프로세스가 백그라운드에 남으면 소리 계속 남
  Ctrl+C 없이 터미널 닫으면 재생 지속 가능.
  pkill -x play_mp3.py로 명시적 종료 필요.

[2] 중복 실행 방지 락
  이미 실행 중이면 "이미 다른 play_mp3.py가 재생 중" 메시지 후 종료.

[3] pygame vs aplay 이중 구조
  2_speaker/4_loadtest : aplay
  7_player             : pygame
  동시 실행 시 ALSA 장치 점유 충돌 가능.

[4] requirements.txt 없음
  pygame 설치 여부 수동 확인: pip install pygame

[5] 6_FFT masking_sounds와 파일 중복
  7_player는 3개만, 6_FFT는 18개 보유.
  노이즈 유형별 자동 선택 로직은 아직 미연결 (수동 재생만).

[6] LED 동시 사용
  SPI LED(1_LED)와 충돌 없음.
  다만 CPU·메모리 부하 시 pygame 버퍼 언더런 가능.

[7] 15_player_ai와의 차이
  7_player  : pygame + MP3 루프 (수동 실행, 폴더 내 MP3 일괄 재생)
  15_player_ai : PyAudio + pydub (14번 명령 수신, 개별 트랙·음량 제어)
  동시 실행 시 ALSA 장치 점유 충돌. 하나만 사용할 것.
