9_send_firebase
================================================================================

작성일: 2026-06-23 (최초 2026-06-17)
경로: /data/9_send_firebase


개요
--------------------------------------------------------------------------------

마이크로 4초간 녹음 → FFT 노이즈 분석 + YAMNet API 분류 → Firebase에 noiseEvents 전송하는
PuriSound 핵심 백엔드 스크립트입니다.

8_MIC_FFT(FFT)와 5_noise_client(YAMNet)를 결합한 프로덕션 지향 모듈입니다.


주요 파일
--------------------------------------------------------------------------------

  send_firebase.py   메인 (녹음·분석·전송 루프)
  plot_wav_grid.py   last_capture.wav 파형·FFT 시각화 (디버그용)
  firebase.json      Firebase 서비스 계정 키 (민감 정보)
  requirements.txt   numpy, scipy, PyAudio, requests, firebase-admin
  .venv/             전용 가상환경 (ensure_project_venv 자동 전환)
  .send_firebase.pid 단일 인스턴스 PID (USB 마이크 중복 점유 방지)
  last_capture.wav   마지막 녹음 샘플 (디버그용, 자동 생성)
  send_firebase.log  실행 로그


실행 방법
--------------------------------------------------------------------------------

  cd /data/9_send_firebase
  python3 send_firebase.py --dry-run          # Firebase 없이 로컬만
  python3 send_firebase.py --list-devices
  python3 send_firebase.py -d USB
  python3 send_firebase.py --no-yamnet        # FFT만
  python3 send_firebase.py --rtdb             # Realtime DB 사용

  # venv 명시
  .venv/bin/python3 send_firebase.py


데이터 흐름
--------------------------------------------------------------------------------

  1. PyAudio로 4초 오디오 수집
  2. 바람 필터(고역통과 120Hz) 적용 (옵션)
  3. 8_MIC_FFT.classify_noise() → FFT 분류
  4. YAMNet POST /classify (http://192.168.0.59:5000)
  5. noiseType(brown/pink/white), db, frequencyHz, yamnetLabel 등 생성
  6. Firestore: devices/{deviceId}/noiseEvents 에 저장
  7. devices/{deviceId} 문서의 decibel, updatedAt 갱신

프로젝트 내 역할
--------------------------------------------------------------------------------

  - PuriSound 앱과 연동되는 노이즈 이벤트 파이프라인
  - 13_noise_db가 이 데이터를 Firebase에서 조회·표시
  - 14_noise_ai가 noiseEvents를 읽어 마스킹 결정 (13→14 연계)
  - maskingRequired 필드 포함 — 14번이 자동 마스킹 파이프라인 담당


주요 이슈
--------------------------------------------------------------------------------

[1] firebase.json 민감 정보
  서비스 계정 키가 폴더에 존재. Git 업로드·공유 금지.
  --dry-run으로 키 없이 로컬 테스트 가능.

[2] YAMNet 서버 의존
  기본 http://192.168.0.59:5000 — 서버 꺼지면 FFT만 사용.
  매 전송 주기마다 서버 상태 체크 (부하 가능).

[3] 바람소리 필터
  wind_score >= 0.55이면 Firebase 전송 생략.
  실외/창가 환경에서 정상 소음도 스킵될 수 있음.
  --no-wind-filter로 비활성화 가능.

[4] 8_MIC_FFT 경로 의존
  sys.path에 ../8_MIC_FFT 삽입.
  8_MIC_FFT 폴더 이동/삭제 시 동작 불가.

[5] venv 분산
  1_LED/venv (rpi_ws281x)
  9_send_firebase/.venv (firebase-admin 등)
  8_MIC_FFT (venv 없음, send_firebase venv에서 간접 사용)
  통합 venv 검토 필요.

[6] 단일 인스턴스 제한
  .send_firebase.pid로 중복 실행 방지.
  12_total, 9_send_firebase 등 마이크 사용 프로세스 동시 실행 불가.

[7] 마이크 연결 재시도
  USB 마이크 미연결 시 12초간 1초 간격 재시도 후 종료.

[8] 네트워크 필수
  Firebase + YAMNet 모두 외부 서버 접근 필요.
  오프라인 환경에서는 --dry-run 또는 --no-yamnet만 가능.

[9] db 변환
  DBFS_TO_DB_OFFSET=100으로 dBFS→표시 dB 변환.
  20~120 범위로 클램핑. legacy noise_controller의 db_offset=100과 동일 개념.
