개요
--------------------------------------------------------------------------------

프로젝트 개발 중 작성된 메모·문서 보관 폴더입니다.
하드웨어 설정, 오류 해결, 아키텍처 결정 사항이 정리되어 있습니다.

이번에 추가된 폴더별 설명 파일(1_LED.txt ~ legacy.txt)도 이 폴더에 있습니다.


기존 메모 파일
--------------------------------------------------------------------------------

  1. led_error.txt
    - 1_LED 실행 오류 정리 (rpi_ws281x, SPI, GPIO busy 등)
    - 올바른 실행: ./venv/bin/python3 neopixel_test.py

  2. audio_led_plan.txt
    - SPI(GPIO 10) LED + 내장 오디오 동시 사용 가능 근거
    - PWM(GPIO 12) 방식은 오디오와 충돌 → 사용 안 함
    - 전원 분리, 멀티스레드 통합 계획

  3. speaker_mic_choice.txt
    - USB 마이크 + 3.5mm 스피커 권장 (Pi USB 전류 절약)
    - USB 스피커는 전원 허브 필요
    - 3.5mm는 자체 전원 앰프 필수

  4. python3_venv_memo.txt
    - ensure_venv.py 자동 venv 전환 설명
    - LED/부하테스트는 venv, 스피커/마이크는 시스템 python3

프로젝트 전체 주요 이슈 (크로스커팅)
--------------------------------------------------------------------------------

[1] venv 분산
  1_LED/venv, 9_send_firebase/.venv, 5_noise_client/.venv
  8_MIC_FFT는 venv 없음. 통합 가상환경 검토.

[2] 오디오 스택 이중화
  ALSA(arecord/aplay) : 2_speaker, 3_mic, 4_loadtest
  PyAudio             : 8_MIC_FFT, 9_send_firebase
  pygame              : 7_player, legacy

[3] YAMNet 서버 외부 의존
  IP 192.168.0.59:5000 하드코딩. 오프라인 시 FFT만 동작.

[4] 마스킹 파이프라인 이중 구조
  분리형: 9 → 14 → 15 → 16 (운영 권장, 3~4터미널)
  통합형: 12_total (단일 프로세스, 데모용)
  수동형: 7_player + 11_led_connect (테스트용)

[7] 마스킹 사운드 경로 불일치
  14번: 10_masking (프로필+MP3)
  12번: 10_masking 프로필 + 6_FFT MP3
  경로·프로필 통일 필요.

[5] ALSA card 번호 환경 의존
  plughw:1,0(스피커), plughw:3,0(마이크) — 자동 탐지 있으나 기본값 고정.

[6] 전원
  LED + USB 마이크 + 앰프 동시 사용 시 Pi USB 전원 부족 가능.
  각 하드웨어 별도 전원 + GND 공통 권장.
