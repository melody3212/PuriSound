오디오 + 스피커 + LED 동시 사용 계획 정리
================================================================================

작성일: 2026-06-17
대상 경로: /data/1_LED


결론
--------------------------------------------------------------------------------

현재 방식(SPI + GPIO 10)은 오디오, 스피커, LED를 한번에 작동시키기에
가장 좋은 선택이다. 지금 구성을 그대로 유지해도 괜찮다.


왜 괜찮은가
--------------------------------------------------------------------------------

라즈베리파이에서 LED를 제어하는 방식은 크게 두 가지다.

[SPI 방식 - 현재 사용 중]
  핀          : GPIO 10 (물리 핀 19)
  내장 오디오 : 충돌 없음
  현재 설정   : dtparam=spi=on, dtparam=audio=on 동시 사용 가능

[PWM 방식 - 사용하지 않음]
  핀          : GPIO 12 / GPIO 18
  내장 오디오 : 충돌 있음 (snd_bcm2835와 PWM 하드웨어 공유)
  필요 조치   : dtparam=audio=off, setup_pwm_audio.sh 실행 필요

현재 neopixel_test.py는 SPI 모드로 동작하며, LED 점등도 확인되었다.
하드웨어 충돌 없이 오디오와 LED를 동시에 사용할 수 있는 구성이다.

setup_spi.sh 주석:
  "WS2812B SPI 모드(GPIO 10) — 내장 오디오와 충돌 없음"


PWM 관련 파일 (현재 경로에서는 불필요)
--------------------------------------------------------------------------------

  setup_pwm_audio.sh  : PWM(GPIO 12) LED용, 내장 오디오 비활성화
  pwm_audio.py        : snd_bcm2835 해제 유틸

SPI LED를 계속 쓸 경우 위 파일들은 실행하지 않아도 된다.


스피커 종류별 호환성
--------------------------------------------------------------------------------

[3.5mm 잭 + 스피커/앰프]
  내장 오디오(dtparam=audio=on) 그대로 사용 가능
  SPI LED와 충돌 없음

[USB 스피커]
  GPIO/SPI와 거의 무관, 가장 단순
  SPI LED와 충돌 없음

[I2S DAC/앰프]
  GPIO 10(SPI LED)과 핀만 겹치지 않으면 사용 가능
  별도 I2S 핀 설정 필요


나중에 통합할 때 신경 쓸 것
--------------------------------------------------------------------------------

1. 전원 (하드웨어)
   LED 16구 + 스피커/앰프는 전류를 많이 소모한다.
   라즈베리파이 USB 전원만으로는 부족할 수 있다.
   LED, 앰프는 별도 5V 전원 사용을 권장한다.
   GND는 라즈베리파이와 공통으로 연결한다.

2. 소프트웨어 구조
   한 프로세스에서 오디오 재생 + LED 애니메이션을 동시에 실행한다.

   메인 프로그램
   ├── 오디오 스레드 (재생)
   └── LED 스레드 (애니메이션)

   rpi_ws281x의 strip.show()와 오디오 재생(pygame, sounddevice, aplay 등)을
   동시에 돌리는 패턴이 일반적이다.

3. core_freq=250
   Pi 3에서 WS2812 SPI 타이밍을 맞추기 위한 설정이다.
   오디오와 직접 충돌하지는 않는다.
   현재 LED가 정상 동작하면 그대로 유지하는 것이 안전하다.

4. venv 통합
   나중에 오디오 라이브러리도 같은 venv에 설치해 관리한다.
   시스템 Python과 venv를 혼용하면 패키지 누락 오류가 발생할 수 있다.


피해야 할 것
--------------------------------------------------------------------------------

  LED를 PWM 모드(GPIO 12)로 바꾸면서 dtparam=audio=on 유지
    -> 오디오 깨짐 또는 LED 오동작

  test_led.py(GPIO 12)와 neopixel_test.py(GPIO 10) 동시 실행
    -> GPIO 점유 충돌 가능

  setup_pwm_audio.sh 실행 (SPI LED 사용 시 불필요)
    -> 내장 오디오가 꺼져서 오디오 기능 사용 불가


현재 하드웨어/설정 상태
--------------------------------------------------------------------------------

  SPI (/dev/spidev0.0)  : 활성화됨
  dtparam=spi=on        : 설정됨
  dtparam=audio=on      : 설정됨 (SPI LED와 충돌 없음)
  core_freq=250         : 설정됨
  LED 핀                : GPIO 10 (물리 핀 19, SPI MOSI)
  LED 개수              : 16구 (WS2812B)


권장 실행 명령 (LED)
--------------------------------------------------------------------------------

  cd /data/1_LED
  ./venv/bin/python3 neopixel_test.py


다음 단계 (오디오 통합 시)
--------------------------------------------------------------------------------

  1. 스피커 종류 결정 (3.5mm / USB / I2S)
  2. 오디오 재생 라이브러리 선택 (pygame, sounddevice, aplay 등)
  3. 같은 venv에 오디오 패키지 설치
  4. LED 제어 + 오디오 재생을 하나의 메인 프로그램으로 통합
  5. LED, 앰프 전원 분리 및 GND 공통 연결 확인
