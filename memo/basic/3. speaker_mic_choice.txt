스피커 / 마이크 선택 가이드 (전류 문제 기준)
================================================================================

작성일: 2026-06-17
대상: 라즈베리파이 + LED(SPI) + 오디오 통합 프로젝트


결론
--------------------------------------------------------------------------------

마이크를 USB로 쓸 예정이라면, 스피커는 3.5mm + 자체 전원 앰프/스피커를 추천한다.

  USB 마이크  -> Pi USB
  3.5mm 스피커 -> Pi 3.5mm 잭 (스피커/앰프는 자체 전원)
  LED         -> GPIO 10 + 별도 5V 전원


왜 3.5mm 스피커가 유리한가
--------------------------------------------------------------------------------

라즈베리파이 USB 포트 전류는 한정되어 있다.
Pi 3 기준 4개 포트 합산 약 1.2A 전후.

[USB 마이크 + USB 스피커]
  둘 다 Pi USB에서 전력을 가져감 -> 부담 큼

[USB 마이크 + 3.5mm 스피커]
  마이크만 USB 사용 -> 부담 적음

LED도 전류를 많이 쓰므로, Pi USB에 마이크와 스피커를 동시에 올리면
아래 문제가 생길 수 있다.

  - 전압 강하 (번개 아이콘)
  - 재부팅 / 불안정
  - USB 장치 인식 끊김


3.5mm 스피커 사용 시 주의
--------------------------------------------------------------------------------

앰프 없는 일반 3.5mm 스피커는 Pi에서 소리가 거의 나지 않는다.

사용할 것:
  - 3.5mm 입력 + 자체 전원(어댑터)이 있는 앰프/스피커
  - 또는 3.5mm -> USB 전원 앰프 모듈 (앰프 전원은 별도)

Pi는 약한 라인아웃 신호만 출력하고,
큰 소리와 전력은 앰프/스피커 쪽에서 처리한다.

현재 SPI LED 구성(dtparam=audio=on)과도 잘 맞는다.


USB 스피커가 나은 경우
--------------------------------------------------------------------------------

  - 음질을 더 신경 쓰고 싶을 때 (Pi 3.5mm DAC 음질은 보통 수준)
  - 반드시 전원이 있는 USB 허브를 사용할 때

허브가 전원을 공급하면 Pi 부담은 줄어든다.
Pi USB 포트에 직접 꽂는 것은 비추천.


비교표
--------------------------------------------------------------------------------

  항목              USB 스피커              3.5mm + 자체전원 앰프
  ----------------------------------------------------------------
  Pi 전류 부담      큼                      작음
  USB 마이크 궁합   포트/전류 경쟁          역할 분리 (입력 USB / 출력 3.5mm)
  음질              보통 좋음               앰프 품질에 따름
  설정 난이도       USB 장치 2개 관리       비교적 단순
  LED 동시 사용     전류 여유 적음          유리


권장 최종 구성
--------------------------------------------------------------------------------

  [입력]  USB 마이크        -> Pi USB
  [출력]  3.5mm 스피커      -> Pi 3.5mm 잭 (자체 전원 앰프/스피커)
  [LED]   WS2812B 네오픽셀  -> GPIO 10 (SPI) + 별도 5V 전원
  [전원]  Pi / LED / 앰프  -> 각각 분리, GND만 공통


USB 스피커를 꼭 쓰고 싶다면
--------------------------------------------------------------------------------

  - 전원 있는 USB 허브 필수
  - 마이크와 스피커를 허브에 연결
  - 허브 어댑터로 전력 공급 (Pi USB에서 전력을 빼지 않도록)

그래도 LED + 마이크 + 스피커를 동시에 쓸 때는
3.5mm 스피커 방식이 더 안정적이다.


소프트웨어 참고
--------------------------------------------------------------------------------

  USB 마이크 + 3.5mm 출력 구성:
    입력 장치: USB 마이크 (ALSA/PulseAudio/PipeWire에서 선택)
    출력 장치: bcm2835 (내장 3.5mm)

  장치 목록 확인:
    arecord -l    (녹음/마이크)
    aplay -l      (재생/스피커)
