1_LED
================================================================================

작성일: 2026-06-17
경로: /data/1_LED


개요
--------------------------------------------------------------------------------

라즈베리파이에서 WS2812B 네오픽셀 LED 스트립(16구)을 SPI 모드로 제어하는 테스트 코드입니다.
GPIO 10(물리 핀 19, SPI MOSI)을 사용하며, 내장 오디오(dtparam=audio=on)와 충돌하지 않습니다.

이 프로젝트의 하드웨어 기반 모듈로, 4_loadtest에서 LED 스레드를 위해 재사용됩니다.


주요 파일
--------------------------------------------------------------------------------

  config.py          LED 핀·개수·밝기 등 설정
  neopixel_test.py   메인 테스트 (색 채우기, 순차 점등, 무지개 애니메이션)
  ensure_venv.py     시스템 python3 실행 시 venv로 자동 전환
  setup_spi.sh       SPI 활성화 + core_freq=250 설정 스크립트
  requirements.txt   rpi-ws281x==5.0.0
  venv/              rpi-ws281x 전용 가상환경


실행 방법
--------------------------------------------------------------------------------

  cd /data/1_LED
  python3 neopixel_test.py
  # 또는
  ./venv/bin/python3 neopixel_test.py

Ctrl+C로 종료 시 모든 LED가 OFF 됩니다.


하드웨어 설정
--------------------------------------------------------------------------------

  LED 개수   : 16구 (WS2812B)
  제어 핀    : GPIO 10 (물리 핀 19)
  전원       : LED는 별도 5V 권장, GND는 Pi와 공통
  SPI        : /dev/spidev0.0 필요
  config.txt : dtparam=spi=on, core_freq=250


프로젝트 내 역할
--------------------------------------------------------------------------------

  - LED 단독 동작 확인용 1단계 모듈
  - 4_loadtest가 이 폴더의 venv·ensure_venv·config를 import하여 LED 스레드 구동
  - SPI 방식이라 2_speaker(3.5mm), 3_mic(USB)와 동시 사용 가능


주요 이슈
--------------------------------------------------------------------------------

[1] ModuleNotFoundError: No module named 'rpi_ws281x'
  원인: 시스템 Python으로 실행
  해결: venv Python 사용 (ensure_venv.py가 자동 전환)

[2] SPI 비활성화 오류
  원인: /dev/spidev0.0 없음
  해결: sudo /data/1_LED/setup_spi.sh 후 sudo reboot

[3] GPIO busy (구버전 test_led.py 사용 시)
  원인: GPIO 12 점유 충돌
  해결: 점유 프로세스 종료. 현재 neopixel_test.py는 GPIO 10 사용으로 무관

[4] LED 켜지지 않음
  원인: 배선, 전원, SPI 설정 문제
  확인: GPIO 10 배선, 외부 5V 전원, SPI 활성화 상태

[5] venv 혼용
  rpi-ws281x는 1_LED/venv에만 설치됨.
  다른 폴더에서 LED 제어 시 반드시 이 venv 또는 ensure_venv 경로 사용.
