8_MIC_FFT
================================================================================

작성일: 2026-06-17
경로: /data/8_MIC_FFT


개요
--------------------------------------------------------------------------------

USB 마이크 입력을 실시간 FFT(Welch)로 분석해 주변 노이즈 유형을 2초마다 터미널에 출력하는 모듈입니다.
9개 세분 대역(저음역 3 + 중음역 3 + 고음역 3)으로 분류하며, 50/60Hz 험음·백색소음 특성도 감지합니다.

3_mic(arecord 단순 테스트)의 고급 분석 버전이며, 9_send_firebase의 핵심 분석 엔진입니다.


주요 파일
--------------------------------------------------------------------------------

  noise_analyzer.py   FFT 분석·분류·리포트 출력 (메인 + 라이브러리)
  requirements.txt    numpy, scipy, PyAudio


실행 방법
--------------------------------------------------------------------------------

  cd /data/8_MIC_FFT
  pip install -r requirements.txt   # 최초 1회
  python3 noise_analyzer.py
  python3 noise_analyzer.py --list-devices
  python3 noise_analyzer.py -d USB
  python3 noise_analyzer.py --interval 2


분류 체계
--------------------------------------------------------------------------------

  저음역: L1(초저역 20-100), L2(저역 100-300), L3(중저역 300-500)
  중음역: M1(500-1200), M2(1200-2500), M3(2500-4000)
  고음역: H1(4000-7000), H2(7000-10000), H3(10000-16000)

  특수 감지:
    - 50/60Hz 험음 (harmonic_score)
    - 백색소음/팬 잡음 (spectral_flatness)
    - RMS < 0.003 → "조용함"


출력 정보
--------------------------------------------------------------------------------

  유형, 설명, 신뢰도
  RMS dBFS, 중심주파수, 지배톤
  음역별·세분 대역별 에너지 비율 바 차트


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 실시간 노이즈 분석 핵심 모듈
  - 9_send_firebase가 classify_noise, pick_default_input_device 등 import
  - 6_FFT(마스킹 MP3 프로필)와 결합하면 노이즈→마스킹 자동 매칭 가능


주요 이슈
--------------------------------------------------------------------------------

[1] PyAudio + portaudio 의존
  apt install portaudio19-dev python3-pyaudio 또는 pip install PyAudio
  3_mic의 arecord 방식과 달리 빌드/설치 이슈 가능.

[2] ALSA vs PyAudio 장치 선택 방식 다름
  3_mic     : plughw:3,0 (ALSA 문자열)
  8_MIC_FFT : PyAudio device index/name
  --list-devices로 인덱스 확인 필요.

[3] 샘플레이트 자동 협상
  기본 48000Hz, 장치 미지원 시 44100/32000 등으로 폴백.
  분석 결과 비교 시 샘플레이트 차이 고려.

[4] 2초 분석 주기 vs 9_send_firebase 4초
  noise_analyzer: ANALYSIS_SECONDS=2, REPORT_INTERVAL=2
  send_firebase  : RECORD_SECONDS=4, SEND_INTERVAL=4
  통합 시 주기 통일 검토.

[5] 분류 정확도
  휴리스틱 기반(FFT + 규칙). YAMNet(5_noise_client)과 병용 시 정확도 향상.
  9_send_firebase에서 이미 YAMNet+FFT 결합 구현됨.

[6] venv 없음
  시스템 python3에 numpy/scipy/PyAudio 설치 필요.
  9_send_firebase/.venv에 패키지가 있으나 8_MIC_FFT 자체 venv는 없음.
