16_led_ai
================================================================================

작성일: 2026-06-23
경로: /data/16_led_ai


개요
--------------------------------------------------------------------------------

14/15_player_ai 재생 상태를 읽어 WS2812B LED에 노이즈 색상 그라데이션을
표시하는 foreground LED 프로세스입니다.

11_led_connect(7_player 연동)의 고도화 버전으로,
다중 트랙 레이어에 맞춘 링 회전 그라데이션을 지원합니다.


주요 파일
--------------------------------------------------------------------------------

  led_run.py          메인 (재생 상태 폴링 → LED 그라데이션)
  led_controller.py   WS2812B SPI 제어 + render_gradient()
  play_state.py       14/15 IPC 상태 파일 통합 읽기
  noise_colors.py     brown/pink/white 스펙트럼·RGB 매핑
  ensure_venv.py      1_LED venv 자동 전환
  requirements.txt    rpi-ws281x
  run.sh              실행 래퍼


실행 방법
--------------------------------------------------------------------------------

  cd /data/16_led_ai
  python3 led_run.py
  python3 led_run.py --poll-interval 0.12
  ./run.sh

  종료: Ctrl+C
  강제 종료: pkill -f led_run.py


동작 구조
--------------------------------------------------------------------------------

  1. /tmp/led_ai.lock 획득 (중복 실행 방지)
  2. play_state.resolve_playback_tracks()로 현재 재생 트랙 확인
     - 우선: /tmp/player_ai_status.json (15번)
     - 폴백: /tmp/player_ai_command.json (14번)
     - 레거시: /tmp/play_mp3_state.json (7번)
  3. 트랙별 noise_type → RGB 스펙트럼 변환
  4. led_controller.render_gradient()로 링 회전 (ROTATION_SPEED=0.1, 약 10초/바퀴)
  5. 재생 없으면 OFF_CONFIRM_POLLS(4회) 후 LED OFF


상태 파일 우선순위 (play_state.py)
--------------------------------------------------------------------------------

  1. /tmp/player_ai_status.json  — 15_player_ai 재생 상태 (audible, tracks)
  2. /tmp/player_ai_command.json — 14_noise_ai 최신 명령
  3. /tmp/play_mp3_state.json    — 7_player 레거시 상태
  stale 판정: 8초 이상 갱신 없으면 재생 중단으로 간주


LED 애니메이션
--------------------------------------------------------------------------------

  - 16구 WS2812B, GPIO 10 (SPI)
  - 다중 트랙: 트랙별 색상을 링에 배치, phase 회전
  - 단일 트랙: 해당 noise_type 스펙트럼 그라데이션
  - brown=저음(빨강계), pink=중음(분홍), white=고음(흰색/파랑)


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 14(결정) + 15(재생) 파이프라인의 시각 피드백
  - 11_led_connect의 7_player 전용 버전을 14/15 IPC로 확장
  - 12_total의 led_worker subprocess와 유사하나 독립 프로세스


주요 이슈
--------------------------------------------------------------------------------

[1] 15_player_ai 선행 권장
  15번 없이 14번만 실행 시 command.json 기반으로 LED 표시 가능하나,
  status.json이 더 정확한 audible 상태 반영.

[2] 1_LED venv 필수
  rpi-ws281x는 1_LED/venv. ensure_venv.py 자동 전환.

[3] 11_led_connect와 선택
  7_player 수동 재생 시: 11_led_connect
  14/15 자동 마스킹 시: 16_led_ai
  동시 실행 시 LED GPIO 충돌 — 하나만 실행.

[4] foreground 프로세스
  15번과 마찬가지로 터미널 세션에 묶임.
  서비스 등록 시 14·15·16을 함께 관리 권장.

[5] SPI + 오디오 동시 사용
  GPIO 10 SPI LED와 3.5mm 오디오는 충돌 없음 (1_LED에서 검증됨).
