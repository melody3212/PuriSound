15_player_ai
================================================================================

작성일: 2026-06-23
경로: /data/15_player_ai


개요
--------------------------------------------------------------------------------

14_noise_ai가 /tmp/player_ai_command.json에 기록한 재생 명령을 폴링하여
마스킹 MP3를 foreground에서 재생하는 전용 플레이어입니다.

7_player(pygame)와 달리 PyAudio + pydub 기반이며,
개별 트랙 경로·음량·최대 3트랙 레이어를 정밀 제어합니다.


주요 파일
--------------------------------------------------------------------------------

  player_run.py       메인 (명령 폴링 → 재생/정지)
  play_mp3.py         MaskingPlayer (PyAudio + pydub, MP3 디코딩·믹싱)
  player_command.py   IPC 경로·명령/상태 JSON 헬퍼
  requirements.txt    PyAudio, pydub, numpy
  run.sh              실행 래퍼


실행 방법
--------------------------------------------------------------------------------

  cd /data/15_player_ai
  python3 player_run.py
  python3 player_run.py --poll-interval 0.15
  python3 player_run.py --audio-dev plughw:CARD=Headphones,DEV=0
  ./run.sh

  종료: Ctrl+C
  강제 종료: pkill -f player_run.py


동작 구조
--------------------------------------------------------------------------------

  1. /tmp/player_ai.lock 획득 (중복 실행 방지)
  2. /tmp/player_ai_command.json 폴링 (기본 0.15초)
  3. seq 변경 시 명령 적용:
     - action=play → play_tracks(경로, 음량, noise_type)
     - action=stop → stop()
  4. /tmp/player_ai_status.json 에 적용 결과 기록
  5. /tmp/player_ai_daemon.pid 에 PID 기록 (16_led_ai 연동)


IPC 파일
--------------------------------------------------------------------------------

  입력: /tmp/player_ai_command.json  (14_noise_ai가 작성)
  출력: /tmp/player_ai_status.json  (재생 상태, audible, tracks)
  락  : /tmp/player_ai.lock, /tmp/player_ai_daemon.pid


오디오 특징
--------------------------------------------------------------------------------

  - PyAudio + pydub (7_player의 pygame과 다른 스택)
  - 3.5mm 잭: plughw:CARD=Headphones,DEV=0
  - 최대 3트랙 동시 믹싱 (MAX_TRACKS=3)
  - 출력: 44100Hz, 스테레오, 16bit
  - MP3 → pydub 디코딩 → PyAudio 스트림 출력


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 14_noise_ai 마스킹 결정의 실행부
  - 16_led_ai가 player_ai_status.json을 읽어 LED 그라데이션 표시
  - 7_player는 수동 재생용, 15번은 자동 마스킹 파이프라인용


주요 이슈
--------------------------------------------------------------------------------

[1] 7_player와 동시 실행 금지
  둘 다 3.5mm ALSA 장치 점유. 하나만 실행할 것.

[2] pydub + ffmpeg 필요
  MP3 디코딩에 ffmpeg 필요. apt install ffmpeg.

[3] 14번 선행 없으면 대기
  명령 파일 없으면 무음 대기 상태 유지.
  14번 --dry-run으로 테스트 명령 생성 가능.

[4] foreground 프로세스
  백그라운드 실행 시 터미널 닫으면 종료될 수 있음.
  systemd 등 서비스 등록 검토.

[5] play_mp3.py 중복
  7_player/play_mp3.py(pygame)와 이름 같으나 구현 완전히 다름.
  15_player_ai/play_mp3.py(PyAudio)만 14번과 연동.
