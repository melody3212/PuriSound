11_led_connect
================================================================================

작성일: 2026-06-23
경로: /data/11_led_connect


개요
--------------------------------------------------------------------------------

7_player 재생 중인 노이즈 색상(brown/pink/white)에 맞춰 WS2812B LED 색상을
동기화하는 모듈입니다. 7_player가 기록하는 /tmp/play_mp3_state.json을 폴링하여
LED 펄스 애니메이션을 표시합니다.

16_led_ai(14/15번 연동) 이전의 단순 LED 동기화 프로토타입입니다.


주요 파일
--------------------------------------------------------------------------------

  led_noise_sync.py   메인 (7_player 상태 폴링 + LED 제어)
  led_controller.py   WS2812B SPI 제어 (1_LED/config 재사용)
  noise_colors.py     brown/pink/white → RGB 매핑
  ensure_venv.py      1_LED venv 자동 전환
  requirements.txt    rpi-ws281x==5.0.0


실행 방법
--------------------------------------------------------------------------------

  cd /data/11_led_connect
  python3 led_noise_sync.py                    # 7_player 실행 중일 때 LED 동기화
  python3 led_noise_sync.py --spawn-player     # 7_player도 함께 실행
  python3 led_noise_sync.py --demo             # brown→pink→white 데모 (7_player 불필요)


동작 구조
--------------------------------------------------------------------------------

  1. /tmp/play_mp3.lock 에서 7_player PID 확인
  2. /tmp/play_mp3_state.json 에서 tracks[].noise_type 읽기
  3. noise_colors.rgb_for_noise_type()으로 RGB 변환
  4. led_controller.pulse()로 펄스 애니메이션 (PULSE_SPEED=2.5)
  5. 재생 없으면 LED OFF


상태 파일 (7_player 연동)
--------------------------------------------------------------------------------

  /tmp/play_mp3.lock        7_player PID
  /tmp/play_mp3_state.json  재생 트랙·noise_type·primary_noise_type


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 7_player + LED 동시 동작 검증 (2프로세스 구조)
  - 12_total은 led_worker.py로 유사 기능을 통합 프로세스 내에서 처리
  - 16_led_ai가 14/15번 IPC 기반으로 대체 (그라데이션, 다중 트랙 지원)


주요 이슈
--------------------------------------------------------------------------------

[1] 7_player 의존
  --spawn-player 없이 실행 시 7_player를 별도 터미널에서 먼저 실행해야 함.
  15_player_ai 사용 시 play_mp3_state.json 형식이 달라 11번과 호환 안 됨.

[2] 1_LED venv 필수
  rpi_ws281x는 1_LED/venv에 설치. ensure_venv.py가 자동 전환.

[3] 단일 노이즈 타입 펄스
  16_led_ai의 다중 트랙 그라데이션보다 단순.
  동시 재생 3트랙 시 noise_type 목록으로 zone 펄스.

[4] 16_led_ai와 중복
  11번: 7_player 전용, 펄스 애니메이션
  16번: 14/15 IPC, 그라데이션 링 회전
  실제 운영은 16번 사용 권장.
