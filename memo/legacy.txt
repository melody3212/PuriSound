legacy
================================================================================

작성일: 2026-06-17
경로: /data/legacy


개요
--------------------------------------------------------------------------------

이전 버전(Pi 3B+ 통합)의 소음 감지·마스킹 시스템 코드 보관 폴더입니다.
현재 활성 개발은 1~9 번호 폴더로 분리되었으며, legacy는 참고·마이그레이션용입니다.

legacy/6_FFT/ 에 통합 컨트롤러·플레이어·FFT 분석이 한곳에 모여 있습니다.


주요 파일 (legacy/6_FFT/)
--------------------------------------------------------------------------------

  noise_controller_pi3.py   소음 감지 → dB 임계값 → 마스킹 MP3 자동 재생/정지
  masking_player_pi3.py     실시간 마스킹 플레이어 (4초마다 MP3 교체)
  preanalyze_masking.py     마스킹 MP3 FFT 사전 분석
  audio_utils.py            FFT 프로필, 장치 확인, 마스킹 선택 공통 유틸
  masking_fft_cache.json    분석 캐시 (6_FFT/masking_fft_profiles.json과 유사)
  masking_sounds/           마스킹 MP3 18개
  setup_pi3.sh              Pi 3 환경 설정 스크립트
  requirements.txt          numpy, scipy, PyAudio, pygame 등


noise_controller_pi3.py 동작
--------------------------------------------------------------------------------

  1) masking_sounds FFT 프로필 로드/생성
  2) 마이크·스피커 연결 확인
  3) 실시간 dB 표시
  4) 40dB 이상 5초 지속 → 상쇄 MP3 재생
  5) 재생 중 40dB 이하 5초 지속 → 재생 정지
  6) mic_chunk_to_profile + select_best_masking으로 최적 MP3 선택


현재 프로젝트와의 대응
--------------------------------------------------------------------------------

  legacy noise_controller  →  8_MIC_FFT + 9_send_firebase + 7_player (분리됨)
  legacy preanalyze        →  6_FFT/analyze_masking_fft.py
  legacy masking_player      →  7_player/play_mp3.py
  legacy audio_utils       →  8_MIC_FFT/noise_analyzer.py (부분 대체)


주요 이슈
--------------------------------------------------------------------------------

[1] 코드 중복·분산
  FFT 분석, 마스킹 선택, 재생, Firebase 전송이 여러 폴더로 쪼개짐.
  legacy의 통합 흐름을 참고해 최종 통합 앱 설계 필요.

[2] JSON 형식 차이
  legacy  : masking_fft_cache.json
  6_FFT   : masking_fft_profiles.json
  필드 구조가 다를 수 있음. 통합 시 스키마 정리 필요.

[3] LED 미포함
  legacy는 LED 제어 없음.
  1_LED + legacy 컨트롤러 통합은 아직 미구현.

[4] Firebase 미포함
  legacy는 로컬 마스킹만. 9_send_firebase가 클라우드 연동 담당.

[5] Python 3.13/3.14 혼재
  __pycache__에 cpython-313, cpython-314 파일 공존.
  실행 환경 통일 권장.

[6] 유지보수 정책 불명확
  버그 수정을 legacy에 할지, 새 폴더에 할지 결정 필요.
  권장: 신규 기능은 6~9 폴더에, legacy는 읽기 전용 보관.
