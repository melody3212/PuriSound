6_FFT
================================================================================

작성일: 2026-06-23 (최초 2026-06-17)
경로: /data/6_FFT


개요
--------------------------------------------------------------------------------

마스킹 사운드(MP3/WAV) 파일들의 FFT 주파수 대역별 에너지 비율을 분석해
JSON 프로필(masking_fft_profiles.json)로 저장하는 오프라인 분석 도구입니다.

노이즈 유형(저음/중음/고음)에 맞는 마스킹 MP3를 선택할 때 사용하는 사전 분석 단계입니다.


주요 파일
--------------------------------------------------------------------------------

  analyze_masking_fft.py    FFT 분석 메인 스크립트
  masking_sounds/           마스킹 MP3 18개 (브라운/핑크/화이트 노이즈)
  masking_fft_profiles.json 분석 결과 (18개 프로필, 자동 생성됨)


실행 방법
--------------------------------------------------------------------------------

  cd /data/6_FFT
  python3 analyze_masking_fft.py
  # 폴더·출력 지정
  python3 analyze_masking_fft.py /path/to/sounds /path/to/output.json


분석 대역
--------------------------------------------------------------------------------

  6대역 (상세):
    sub_bass(20-60), bass(60-300), low_mid(300-1000),
    mid(1000-3500), high_mid(3500-8000), high(8000-11000)

  3대역 (매칭용, legacy 호환):
    low(20-300), mid(300-3500), high(3500-11000)

  FILL_THRESHOLD = 0.15 (15% 이상 에너지 대역을 filled_bands로 표시)


의존성
--------------------------------------------------------------------------------

  numpy (필수)
  scipy  : WAV 읽기
  pydub + ffmpeg : MP3 읽기


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 마스킹 사운드 라이브러리 사전 분석
  - legacy/6_FFT의 masking_fft_cache.json과 유사 목적
  - 8_MIC_FFT 실시간 분석 결과와 매칭해 최적 마스킹 MP3 선택 (향후 통합)
  - 7_player의 MP3 파일과 masking_sounds 일부 중복
  - 10_masking이 확장 라이브러리로 분기 (프로필·MP3 20개)
  - analyze_masking_fft.py로 10_masking 프로필도 생성 가능


주요 이슈
--------------------------------------------------------------------------------

[1] MP3 분석 시 pydub + ffmpeg 필요
  ffmpeg 미설치 시 MP3 파일 분석 실패.
  apt install ffmpeg 또는 WAV만 사용.

[2] 짧은 샘플만 분석 (max_samples=8192)
  파일 앞부분 8192샘플만 사용. 전체 곡 특성과 다를 수 있음.

[3] legacy와 중복
  legacy/6_FFT에 통합 컨트롤러(noise_controller_pi3.py) 존재.
  현재 6_FFT는 분석만, legacy는 실시간 재생까지 포함.
  두 JSON 형식(masking_fft_profiles.json vs masking_fft_cache.json) 통합 검토 필요.

[4] requirements.txt 없음
  numpy, scipy, pydub 설치 여부를 수동 확인해야 함.

[5] 7_player와 masking_sounds 중복
  7_player에 3개 MP3, 6_FFT/masking_sounds에 18개 MP3.
  파일 관리·동기화 주의.
