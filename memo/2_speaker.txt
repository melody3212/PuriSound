2_speaker
================================================================================

작성일: 2026-06-17
경로: /data/2_speaker


개요
--------------------------------------------------------------------------------

라즈베리파이 3.5mm 잭(bcm2835 Headphones)을 통한 스피커 출력 테스트 코드입니다.
ALSA aplay로 WAV를 재생하며, 사인파를 직접 생성해 비프·음계·좌우 테스트를 수행합니다.

USB 마이크(3_mic)와 역할을 분리한 출력 전용 모듈입니다.


주요 파일
--------------------------------------------------------------------------------

  config.py          ALSA 장치, 샘플레이트, 음량, 테스트 멜로디 설정
  speaker_test.py    메인 테스트 (비프, 도레미파솔라시도, 좌우 번갈아 비프)


실행 방법
--------------------------------------------------------------------------------

  cd /data/2_speaker
  python3 speaker_test.py
  python3 speaker_test.py --list          # 재생 장치 목록
  python3 speaker_test.py -d plughw:1,0   # 장치 직접 지정


설정값 (config.py)
--------------------------------------------------------------------------------

  ALSA_DEVICE   : plughw:1,0 (card 1 = bcm2835 Headphones)
  SAMPLE_RATE   : 44100 Hz
  VOLUME        : 0.8
  의존성        : 시스템 python3 + alsa-utils (aplay)


프로젝트 내 역할
--------------------------------------------------------------------------------

  - 스피커 단독 동작 확인용 2단계 모듈
  - 4_loadtest가 speaker_test.py 함수(make_tone, write_wav, play_wav)를 import
  - 3_mic의 --playback 옵션도 동일 ALSA 장치(plughw:1,0) 사용


주요 이슈
--------------------------------------------------------------------------------

[1] aplay 장치 오류 / 소리 없음
  원인: card 번호 불일치, 스피커/앰프 미연결
  해결: python3 speaker_test.py --list 로 card 확인
        3.5mm + 자체 전원 앰프/스피커 필요 (Pi 단독 출력은 매우 약함)

[2] plughw:1,0 고정값
  config.py에 card 1이 하드코딩되어 있음.
  find_headphones_device()로 자동 탐지하지만, 환경에 따라 card 번호가 달라질 수 있음.

[3] venv 불필요
  시스템 python3 + aplay만 있으면 동작.
  LED(1_LED)와 동시 실행 시 SPI+오디오 충돌 없음 (검증됨).

[4] 7_player와의 차이
  speaker_test.py : aplay + WAV 사인파 (테스트용)
  7_player        : pygame + MP3 동시 재생 (마스킹 사운드용)
  용도가 다르므로 혼동 주의.
